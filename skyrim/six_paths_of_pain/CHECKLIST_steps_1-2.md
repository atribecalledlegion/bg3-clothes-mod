> **DONE without the CK (2026-10-12).** `SixPathsOfPain.esp` was generated by [tools/build_spp_esp.py](tools/build_spp_esp.py) with every record below, and is in the MO2 mod "Six Paths of Pain". One difference: the class attribute weights use vanilla's small scale (Health 2 / Magicka 3 / Stamina 1), not 40/50/10. Keep this file as the reference for what each record contains, and for the CK setup (Step 1, items 1–3) needed from step 3 on.

The goal is a `SixPathsOfPain.esp` that holds the shared records only. No NPCs, cells or quest yet.

## Step 1: Plugin setup

1. In MO2, **enable** these three mods (left pane). Leave them at the bottom of the list, where they appear:
   - Six Paths of Pain
   - Papyrus Sources - Vanilla
   - CK Only - ESM-Flagged Naruto Masters
2. Launch **Creation Kit** from MO2's executable dropdown. It's already set up there.
3. **File → Data…** and tick:
   - Skyrim.esm, Update.esm, Dawnguard.esm, Dragonborn.esm
   - naruto overhaul.esp
   - UchihaClan.esp (RaceCompatibility.esm loads automatically as its master)

   **Don't** set an active file, because we're creating a new one. Click OK. Answer *Yes to All* to the warning pop-ups. Loading takes a while.
4. **Master check:** Object Window → filter `aaaAkatsukiRobe`. `aaaAkatsukiRobeUnenchanted` should show up. If it doesn't, stop and tell me.
5. **File → Save**, name it `SixPathsOfPain.esp`. It's empty, but that's fine: this just fixes the name and masters.
